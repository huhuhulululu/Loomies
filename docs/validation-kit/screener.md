# 招募筛选表（screener）

> 用途：方法①③ 招募。**核心目标 = 筛出 ICP（大衣橱、用不上、想得体），筛掉干扰项（胶囊/极简自解者）。**
> 可直接搬进 Google Form。目标 N=12-15（管家测试取其中 8-12）。

## 招募伪装（内部，不给受访者看）

以「**职业女性如何应对早晨与穿衣**」研究招募，**不是**「衣橱 App / 穿搭 App」研究——点名 App 会把样本偏向 App 爱好者，毒化 R1 测试。
配额混合：~1/3 试过衣橱 App 并弃用（最高价值）、~1/3 自认已解决（胶囊/制服，作对照+排除练习）、~1/3 自述挣扎。报酬 $25-40 / 30 分钟。

## 筛选问题

1. **年龄**（只收 25-45）：<25 / 25-34 / 35-45 / >45
2. **性别**（目标：女性；措辞包容，主客户画像非绝对门）
3. **所在地 + 气候**：强季节波动 / 全年稳定（招募混合，测天气 vs 场合轴）
4. **办公形态 + 穿着是否有 stakes**：全在办 / 混合 / 全远程；工作穿着是否要紧（客户面对面/dress code）。主招有 stakes 者，少量全远程作对照，**排除制服强制岗**（如只穿 scrubs）
5. **摩擦筛**：过去两周有几个早晨换过至少一次装、或花 >5 分钟决定穿什么？（招募一个 spread，不只高摩擦者）
6. **★衣橱规模（ICP 关键筛）**：小而精选 / 正常衣橱 / **多到记不过来**。**确保有真实选择空间，重点招「多到记不过来」者**
7. **现有解法**（开放+提示）：没特别做什么 / 前一晚摆好 / 胶囊或"制服" / Pinterest 或截图 / 笔记 App 或表格 / 专门衣橱 App / 问伴侣朋友
8. **★App 经历**：下载过衣橱/穿搭 App 吗？还在用还是停了？停了用了多久？**主动招一些「试过并弃用」者——最高价值访谈**
9. **排除利益相关**：你或同住者是否在时尚/服装零售/PR营销/UX产品研究/衣橱造型 App 工作？（是→排除，内部偏见+马甲风险；也排除你认识的人）
10. **可用性**：两周内能否 30 分钟私密视频通话，$[25-40] 礼卡？（确认可录音，只排期确认的 yes）

## ICP vs 干扰项判别（招募时看第 6/7/8 题）

| 信号 | 归类 |
|------|------|
| 「多到记不过来」+ 试过 App 弃用 + 无稳定系统 | ✅ **核心 ICP**（优先招） |
| 「小而精选」+ 胶囊/制服 + 「我这样挺好」 | ⚠️ **干扰项**（招少量作排除对照，别进管家测试主组） |
| 正常衣橱 + 前一晚摆好但仍觉难 | ✅ ICP（次优先） |
