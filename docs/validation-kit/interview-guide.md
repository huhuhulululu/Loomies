# 方法③ 1:1 用户访谈脚本（Mom Test，非诱导）

> 可直接照读。**铁律：问过去真实行为，不问未来假设意愿。绝不提 App。**
> 12-15 人，饱和即停（连续 3 场无新模式）。$25-40 礼卡 / 30 分钟。

## R1 头号陷阱（最重要）

你**想要**「场合」是答案，所以**绝不能植入**——全程不说 occasion / calendar / weather / meetings / dress code / 推荐 / App 任何词，让它自己冒出来。若「场合」只在你诱导后出现、从不自发出现，就当 H1 未证。

## 开场（照读）

> 谢谢抽时间，大概 30 分钟。开始前说明：我不卖任何东西，今天也不给你看任何产品。没有标准答案，我只想了解你的真实情况。可以录音吗？（等同意）

## 问题（按序，追问用「后来呢/能具体说说吗」）

1. 带我过一遍今早（或上个工作日早晨）——从开始想穿什么到出门，实际发生了什么？
2. 那是典型的一天还是更难/更易？说说上一个真正挣扎的早晨——那天怎么了？
3. 这种早晨多久一次？今天之前最近一次是？
4. 难的早晨你实际怎么脱困？
5. 过去一年你试过什么让这件事更轻松——从改习惯到买东西到试任何工具？
6. 试过又停掉的，什么让你停？大概何时弃用？
7. 你为这事花过真金白银吗（造型师/清衣橱/订阅盒/付费 App）？走一遍最近一次付费，值不值？
8. 一周里有没有某些日子/场合你更花心思穿？说说最近一次和它的不同。（**注意：这里"场合"若由她自己说出=强信号；你别先说**）
9. 上次站在满衣橱前还觉得「没衣服穿」，回头看那到底是什么？
10. 当你确实定下一套满意的，通常是什么让它那天成立？
11. 你身边有谁看起来完全搞定了这事——你觉得他们做了什么你没做的？
12. 关于工作穿衣，有什么我该问没问的？

## 分析（每场后即记）

- 「场合/日历」是否**自发**出现（问 1-7 未诱导时）？频率与强度。
- 她想要「有东西替我决定」还是「帮我看清/自己更快决定」？（推荐器 vs 规划器的质性信号）
- 有没有**过去真实的时间/金钱投入**？（有热情但零投入=恭维陷阱，假阳性）
- 恭维陷阱红旗：「这主意不错」「我会用的」——这是陈述，不是证据，追问「上次你为此做了什么」。
