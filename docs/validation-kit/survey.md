# 在线问卷成品

> 可直接搬进 Tally / Typeform（免费）。~4 分钟，匿名，每题可选。
> 两个 cell：A = 日推荐 App 现/流失用户（proxy，测 Sean Ellis PMF）；B = 泛目标职业女性 25-45。
> 样本：Cell A ≥40、Cell B ≥150。招募走 `community-posts.md` + 可选 Prolific。

## 引导语（给受访者）

> 4 分钟匿名调研，关于职业女性如何应对穿衣。无推销、无注册、无产品——我是独立开发者，想在动手前先学习。每题可选。

## 题目

1. **工作设置**：全在办 / 混合 / 全远程 / 目前不工作。工作穿着有真实 stakes（客户会议/dress code/被看见）吗？常有 / 有时 / 很少 / 无
2. **早晨难度频率**：典型工作周，几个早晨真的难以决定穿什么？0 / 1-2 / 3-4 / 5+
3. **★难在哪里（H1 核心测，排前 3）**：(a) 没什么配那天的场合(会议/活动/见谁) (b) 天气变了/不知穿什么应季 (c) 想穿的在洗/不确定啥干净 (d) 不合身/身材变了 (e) 腻了/穿啥都不好看 (f) 记不清我有什么 (g) 选项太多冻住了
   > **判读**：看 (a) 场合是否真排第一。若排不进前二，H1 的「场合」楔子可疑。
4. **场合复杂度**：典型一周你 juggle 几种不同穿着情境？（普通办公/大客户日/居家/晚间活动/周末）1 / 2-3 / 4-5 / 6+
   > 测 H1 假设的场合复杂度是否真存在于她们生活。
5. **现有解法**（多选）：前一晚摆好 / 胶囊或"制服" / Pinterest或截图 / 笔记App或表格 / 专门衣橱App / 问伴侣朋友 / 没特别做
6. **★过去 12 月付费**（多选+金额）：私人造型师 / 清衣橱服务 / 付费衣橱App / 订阅盒(Stitch Fix) / 书或课程 / 无
   > 揭示性支付意愿，强于任何陈述意向。
7. **App 经历**：从没试过 / 试了第一周内弃 / 试了几周后弃 / 还在用。若弃用，一句话说为什么。
8. **★Sean Ellis PMF（pre-launch 改编）**：如果你**再也不能用现在规划/决定穿搭的方式**（App/前一晚routine/胶囊/系统），会多失望？非常失望 / 有点失望 / 不失望 / 我没有系统。
   > 对标经典 40% "非常失望" 阈值（对**现有 workaround** 测；上线后对 beta 用户重跑真版）。「我没系统」+「不失望」占比高=痛点比假设浅。
9. **★开放题**：若魔法助手只能帮你搞定穿衣的**一件事**，你要哪件？（自由填）
   > 故意开放且放最后，让真正 #1 痛点无诱导冒出。**与第 3 题排序交叉验证**：若 (a) 场合赢了强制排序但从没在这里被自己说出，H1 视为未证。
10. **可选**：愿意付费 30 分钟跟进通话就留邮箱（不留=完全匿名）。
