## 1. 执行摘要

- **这是一门小团队可持续生意，不是 VC 级独立大生意**：美国衣橱管理软件品类无公开财报，可证头部收入代理均在 $10⁵–10⁶ ARR 量级（Cladwell 峰值近 $1M、以 ~$33 万 ARR 出售）；SOM 合理锚点为十万级 ARR。商业期望、成本结构、功能野心都应按此校准。
- **需求真实但供给集体失败在执行层**：1,484 条竞品评论一手抓取显示，每日搭配推荐几乎无人质疑需求本身；差评主体 = 推荐执行失败（天气失配/重复推荐/非法组合）+ 商业与工程失败（订阅陷阱/付费墙反悔/崩溃/数据丢失/录入负担）。**把四件基础事做对（天气、场合、防重复、组合合法）就是入场券级差异化。**
- **四个差异化假设经需求侧验证后重新定位**（详见 §2）：每日推荐 GO；体型可视化 GO 但重定位为「合身判断」；存放位置降级为留存钩子；不卡件数已是入场券、隐私是信任设计而非获客钩子。
- **最大威胁是 Alta**（免费、4.9★/11K 评分、周更、$11M、场合叙事重叠），但其品牌导购 B2B2C 变现与我们三个防御点**结构性相斥**（存放/多衣柜不产生 GMV、on-device 隐私与品牌数据合作冲突、诚实合身与卖货动机冲突）。对 Alta 窗口按 0-12 个月计。
- **照片试穿已商品化**：Google Doppl 关停并入 Search/Shopping 免费能力，B 组三家 2026-07 同月上线照片试穿——不要在像素写实上竞争，合身判断是唯一未被做成的空白（Style DNA 收了测量数据但没用起来，有原声为证）。

## 2. 四个差异化假设：go/no-go 判定

| 假设 | 判定 | 需求侧证据 | 定位修正 |
|------|------|-----------|---------|
| H1 场合/天气每日推荐 | **GO** | 「decision fatigue」是目标社区高频自发词；『忘记自己有什么』19 次自发出现（品类第一 JTBD）；竞品差评集中在执行失败而非需求否定。⚠️ 核查修正：差评主体还包含扣费纠纷/崩溃/录入负担等商业工程失败，「100% 指向推荐执行」不成立；「天气正确性是付费转化前置条件」是合理假设非实证 | 四条正确性验收进 v1.0 硬门：天气实时且只算日间时段、场合硬过滤、≥7 天防重复+状态感知、组合语法合法（禁双 blazer/缺下装） |
| H2 存放位置/换季 | **GO-降级** | 美国换季收纳行为普遍（seasonal swap/storage unit/地下室 tub、The Home Edit 主流化），但**未找到任何「想用 App 记衣服在哪个箱」的原声**；Pureple location 字段 150 条评论零提及 | 从获客卖点降为**留存钩子 + 整理师渠道抓手**：推荐卡片内显示「在 xx 箱」、seasonal swap 助手；营销不以它领衔；文案用用户语言 "seasonal swap / the big switcheroo" |
| H3 体型可视化 | **GO-重定位** | 照片 avatar 体型失真是 Doji/Alta 差评首因（「avatar makes you skinny so it defeats the purpose」）；有「想输入身体测量」直接原声；Style DNA 收测量而不用，全行业执行空白 | 定位=**合身判断**（「这件在你的腰臀比上会偏紧」类可解释结论），可视化只是结论的表达层；刻意与像素写实军备赛区隔（诚实体型 vs 被画瘦） |
| H4 不卡件数 + 隐私 | **拆开判定** | 不卡件数：Whering/Indyx 已免费无限——**入场券而非差异化**（但仍必做：平均衣橱 166 件，100 件墙必撞）。隐私：1,484 条评论中几乎零隐私诉求——**不是获客钩子** | 隐私降级为信任设计（身体数据采集弹窗/可导出/永不喂广告）；升级两个可营销的结构性差异：①「没有可以宕机的服务器」（Smart Closet 因服务端 EOL 灾难性丢数据沦为僵尸，实证在案）②「克制的 AI」（接住品类内正冒头的反 AI-slop 情绪） |

**新增的低成本差异点**（需求侧发现）：「距上次洗涤已穿几次」追踪被 Reddit 用户点名「没有任何 App 做」——本产品 Item 状态机已覆盖，显性化即可。桌面/CSV 导入是高频未满足请求，进 roadmap。

## 3. 市场规模与时机

- **品类盘**：美国 wardrobe/outfit App 收入 <$1 亿/年（推断，三条独立证据链互证但无实证财报）；SOM 中位锚 ~$20 万 ARR
- **相邻锚点**（付费能力的旁证）：Stitch Fix FY2025 $1.27B（活跃客户 -7.9%，外包造型衰退=自助工具的顺风）；衣橱整理服务单价 $1.5-5K；美国二手转售 ~$50B、增速 5 倍于服装大盘
- **人群盘**：美国 25-44 女性 ~44M、在职 ~34M（LFP 2024 年创纪录、2026 回落至 ~77.6%）、专业管理岗 13-15M；户均服装年支出 $2,001（BLS 2024，全体 consumer units 口径）
- **趋势峰值区**：capsule wardrobe TikTok 20 亿观看、搜索五年新高；Indyx 一手数据：平均衣橱 166 件、年新增中位 59 件、25% 全年零穿着
- **融资全景**：2024-2026 AI 时尚 7 家代表公司合计 ~$190M（Gensmo $60M、Daydream $50M、Phia $43.5M、Doji $14M、Whering ~$14M 累计、Alta $11M、Vêtir $5.5M），变现全部押购物/佣金/转售。⚠️ 核查修正：「职业女性定位无人占据」不成立——**Alta 已部分占据**（场合叙事 date night/work conference/travel），空白准确说是「衣橱管理深度 × 合身判断 × 存放换季」的组合
- **窗口判断**：品类主流化拐点已到（Clueless 衣橱成自然搜索入口、GMA 电视曝光）；总窗口 12-18 个月，对 Alta 0-12 个月
- **v2 期权**：转售出口——尺码双层分离/实测维度/品牌字段天然是 Poshmark/eBay listing 素材，「导出为转售草稿」低成本高契合（25% 零穿着→处置流向）

  断  │                                          │
      │          ★ 本产品目标位：                 │

      └─────────────────────────────────────────┘

- **Alta**（主威胁）：免费+周更+$11M，衣橱管理功能齐备（收据导入/CPW/打包/场合叙事）；弱点=avatar 体型失真、AI 组合质量、云端架构、无存放/多衣柜/合身判断——且其变现模式结构性不愿做这三点
- **Indyx**（心智竞品）：已占住 9-5 职业女性好感（五星评论满是目标人群），但无场合结构化——我们的场合体系必须做成推荐引擎硬过滤而非手动 Collections 才构成防御
- **GetWardrobe**（唯一活跃盯防）：月更、有身体测量记录+occasion 标签+隐私话术抢跑，但「记录不驱动功能」——fit 引擎是对它的直接降维
- **工具组整体**：无一家同时占据 2+ 差异化格位（组合空白确认，⚠️ 本条未经独立核查）；Stylebook 停更 13 个月仍居付费榜 #2 = 买断工具需求旺盛供给停滞

## 6. 定价与免费层（证据校准）

- 价格锚点（原声实证）：$4.99 买断=口碑金标准（「Best $5 I've ever spent」）；$8/月=长期用户反感线；$60/年被质疑；「一次性收费我就付、订阅不付」直接原声
- 品类现实带：付费档 $30-50/年；服务替代叙事「一次真人造型 $40-200 = 全年 AI 衣橱」
- 红线（血案实证）：100 件墙=1★ 引爆器；录入后才暴露的付费墙=数据扣押感；双轨计费/同名多价 A/B=Style DNA 崩塌路径；涨价触发「Greedy」差评潮
- **结构建议**（对接 DESIGN §6 + Codex 审计发现）：免费层必须完整跑通「录入+每日推荐」核心回路（Alta 免费倾销已拉高基线）；**权益矩阵必须一页说清**（买断=本地功能永久 / 订阅=AI 云端 / 二者重叠区要有明确抵扣），避免被解读为多重付费墙——这是 Codex 独立审计与 11/14 号报告共同点名的结构风险
- 免费层边界一次定对：「不卡件数」承诺一旦做出不可回收

## 7. 增长与冷启动

- **激活北极星**：7 天内数字化 40 件（Whering 创始人自述的留存门槛，单一自报来源未经审计）；配套硬指标——首日 50 件、单件 <15 秒、30 分钟从真实衣橱到首个可信推荐
- **前 1000 用户**（按杠杆排序）：①造型师/衣橱整理师种子计划（渠道完全空白，GetWardrobe Stylist Mode 已验证工具需求；「客户衣橱只读共享」值得评估进 v1.x）②Reddit 三社区（r/femalefashionadvice、r/capsulewardrobe 等——**严禁马甲式营销**，该社区已多次当场揭穿竞品 astroturf）③中腰部创作者 ④Wirecutter 型 earned media（Indyx 验证的路径，与我们人群最匹配；隐私立场是天然媒体选题）
- **ASO 现实**：'digital closet' 前三被 Whering/Alta/Indyx 占据；'outfit planner' 前排仍有中小玩家立足（⚠️ 核查修正：「大词已被占死」过强）；上线前用 Apple Search Ads 后台实测长尾词（work outfit planner / closet inventory / capsule wardrobe planner）
- **获客日历**：1 月（新年整理峰）+ 3-4 月 / 9-10 月（换季）做内容冲刺
- **存量转换不指望**：品类无迁移标准+重拍沉没成本，增长以未数字化衣橱的新增用户为主
- **护城河排序**（被抄难度）：合身闭环 H3 ＞ 成本结构+隐私 H4 ＞ 职业女性心智 H1 ＞ 存放位置 H3（最易被抄，一个版本即可）；防御策略=**合订本**：推荐卡片同屏呈现 合身标记+存放位置+场合——单点可抄、组合体验难抄
