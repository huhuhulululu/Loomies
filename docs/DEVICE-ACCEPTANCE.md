> 建立于 2026-08-13（D199）。**每完成一项就在这里打勾并写上机型/系统版本**——

## 为什么需要这份清单

本仓的自动化是 **1720 条单元测试 + `xcodebuild -destination 'generic/platform=iOS'` 编译**。
这两样合起来能证明的是：**逻辑对、编译过**。它们证明不了的是：

- 相机、Vision 抠图/OCR 在真设备上的**真实推理结果**（模拟器一律 mock）；
- 任何**跨时间**的行为（跨午夜、通知在早上真的响、Widget 时间线真的刷新）；
- 任何**渲染**结果（排版、留白、大字号、深色模式、动效手感）；
- 任何需要**系统权限或云端**的路径（相机/通知授权、App Group、CloudKit）；
- 任何**性能的绝对量级**——本机 load 常年 15+，实测数字不可读
  （见 D185/D197/D198：性能门在满载机器上会随机跨门限）。

每条都写成 **一个动作 + 一个可判真伪的观察**。
读起来像「看看是否正常」的条目一律是坏条目，请改掉。
